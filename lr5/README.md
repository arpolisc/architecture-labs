# ЛР5 — архітектура даних: володіння, кешування та узгодженість

Проєкт ЛР3 (три сервіси та шлюз) доповнено реальними базами даних, міграціями, кешем і надійним обміном подіями.

| Процес      | Порт | База даних (власна)   | Володіє даними                      |
|-------------|------|-----------------------|-------------------------------------|
| gateway     | 3000 | —                     | —                                   |
| orders      | 3001 | `orders.db`           | Замовлення, Клієнт                  |
| restaurants | 3002 | `restaurants.db`      | Ресторан                            |
| delivery    | 3003 | `delivery.db`         | Кур’єр, Доставка; локальна копія запитів на доставку |

Сховище — SQLite (бібліотека `sql.js`, працює без нативної збірки); кожен сервіс відкриває власний файл у каталозі `DATA_DIR`
(за замовчуванням `./data`). Спільної бази даних немає.

## Що нового порівняно з ЛР3
- **Міграції** (`services/*/infrastructure/migrations`): журнал `schema_migrations`; перейменування `orders.courier → courier_id`
  виконано за шаблоном «розширення – скорочення» (міграції 002–004).
- **Транзакційний outbox і журнал оброблених подій** у базі кожного сервісу: події не втрачаються при перезапуску,
  обробка повторних подій ідемпотентна.
- **Кеш** інформації про ресторани в сервісі замовлень: ключ `restaurantId`, TTL 30 с, інвалідизація подією
  `restaurant.availability-changed`.
- **Локальна копія** `dispatch_requests` у сервісі доставки (лише для читання; змінюється тільки власний прапорець `waiting`).

## Запуск
```
npm install
npm test                 # 93 тести: домен, сценарії, міграції, сховище, кеш, контракти, архітектура, інтеграція
npm run demo:migration   # міграція «розширення – скорочення» по етапах
npm run benchmark        # час відповіді до та після введення кешу
npm run demo:data        # кеш, повторна подія, довговічний outbox (запускає процеси сам)
npm run demo             # експеримент ЛР3 з вимкненими сервісами
npm run start:all        # усі процеси; шлюз: http://127.0.0.1:3000/api
```
Змінні середовища: `DATA_DIR`, `BASE_PORT`, `RESTAURANT_CACHE_TTL_MS` (0 вимикає кеш), `RESTAURANTS_TIMEOUT_MS`, `OUTBOX_RETRY_MS`.
