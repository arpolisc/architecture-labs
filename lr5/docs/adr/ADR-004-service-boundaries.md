# ADR-004: межі сервісів і спосіб взаємодії

Статус: запропоновано. Докладний текст — у звіті до ЛР3.
Рішення: три сервіси за доменними контекстами (замовлення, ресторани, доставка) і шлюз; синхронний HTTP
для перевірки ресторану (тайм-аут 1000 мс, відмова — 503), асинхронні події через outbox для переходів між
замовленням і доставкою.
