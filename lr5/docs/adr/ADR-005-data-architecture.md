# ADR-005: архітектура даних

Статус: запропоновано. Докладний текст — у звіті до ЛР5.
Рішення: SQLite (sql.js) як власна база кожного сервісу; зворотно сумісні міграції за шаблоном «розширення – скорочення»;
кеш застосунку з інвалідизацією за подією й запасним TTL; транзакційний outbox і журнал оброблених подій для узгодженості без
розподілених транзакцій. Відхилення від ADR-002 (PostgreSQL + Prisma) обмежене інфраструктурним шаром.
