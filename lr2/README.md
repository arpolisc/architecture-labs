# ЛР2 — багатошарове ядро системи обліку замовлень служби доставки їжі

Стек ЛР2: TypeScript, Node.js, Jest; репозиторії в пам’яті (PostgreSQL і Prisma — у ЛР5).
Відхилення від ADR-002 (NestJS) описане в ADR-003 у звіті.

Шари та каталоги — див. `docs/architecture.md`.

## Запуск
```
npm install
npm test        # доменні, прикладні та архітектурні тести
npm run build
npm start       # демонстрація трьох сценаріїв
```
